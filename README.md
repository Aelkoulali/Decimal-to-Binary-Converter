# 🗂️ Decimal to Binary Converter 🔢
Recursion is a programming technique where a function calls itself to solve a problem by breaking it into smaller, simpler sub-problems. It stops when it reaches a base case—for example, when a value becomes 0 or 1.
In this project, JavaScript converts a decimal number to binary using recursion, then visually explains the process by animating how the call stack builds and unwinds the results.

## ✅ Key Concepts
 
  JavaScript, HTML & CSS
  Recursion concept
  Exploring the call stack
  Building out a visual representation of the recursion process through an animation
